What it does for you

Meru answers questions from your notes and files, and uses the tools you allow. The models run on your computer, so your questions never reach an AI company.

  • Your data stays home

    Your files, mail and questions stay on your computer. Ollama, a free program, runs the models there too.

  • No account and no bill

    Meru needs no sign-up, no cloud model and no subscription. A question costs the electricity your computer uses.

  • Answers from your folders

    You pick the folders Meru may read. It searches them by keyword and by meaning, and names the files behind each answer.

  • Tools you choose

    Mail, calendar, notes, web search and GitHub start switched off. Meru asks you before any call that sends, deletes or changes something.

  • It remembers what you tell it

    Meru keeps what it learns about you as small Markdown files. You can read, edit or delete each one.

  • Every chat is a file you own

    Each conversation lands in one plain text file on your disk, ready to back up, search or delete.

What runs where

Two programs do the work: merud runs in the background, and you ask it questions through meru in the terminal or the desktop app.

What it does for a company

Staff want an assistant, and the data they would use it on can't leave the building. Meru fits that problem.

  • The data stays put. Meru runs on a laptop, a virtual desktop or a server in your own account. It reads email, documents, code and notes without sending any of it to a model provider, so it can work on material that policy or regulation keeps in-house.
  • Tools stay off until you allow them. Each server's tools start switched off, and risky ones ask before they run.
  • Every action lands in a log. Each tool call goes into an audit table and the session transcript. One function, dispatch, handles every call, so a reviewer checks one code path.
  • You can measure it. Meru sends OpenTelemetry metrics and traces (tokens, time, which tool ran and which failed) to a collector you run on the same machine.
  • It installs anywhere. Meru ships as native programs with no interpreter to install. It runs on laptops, virtual desktops, servers on your own network and machines with no internet connection.
  • No per-question bill. You pay for hardware you already own.
  • A license legal teams know. Meru comes under the Apache License 2.0, with an express patent grant. You may use, change and ship it, in your own products included, as long as you keep the notices.

Meru serves one person on one machine today. Central control over who may use which tools, across a company, doesn't exist yet.

Try it on your Mac

Open Terminal and paste this line:

$ curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install.sh | bash
  • The script runs on macOS. On a Mac with Apple silicon it also installs Meru.app, the desktop app.
  • It lists what it will install, then asks once: everything, one step at a time, or quit.
  • It takes several minutes, most of it downloading the models, about 2 GB.
  • It checks every download against the release's checksums. Run it again to update; Meru never checks for updates by itself.

Or install in a window: download the disk image below, open it and open "Install Meru.app". The first time, macOS refuses because Apple hasn't checked Meru: click Done, then Open Anyway in System Settings, Privacy & Security. It walks through each step, says what it downloads first, and sets up web search, your folders and Gmail if you want them.
