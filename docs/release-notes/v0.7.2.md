# Release v0.7.2 - Web search with Podman, and fixes from a first contributor

**November 2026**

Web search now runs SearXNG with Podman on a computer that has no Docker. This release also says plainly when Ollama stops mid-session, starts each new chat on the Auto scope, sends text you give for rewording straight to the model, and fixes Try again and the Usage screen in the desktop app.

---

## Upgrading from v0.7.1

### Breaking changes

There are no breaking changes in this release. Two status sentences changed their words: "Web search needs Docker or Podman, and neither is installed." and "Web search can't start: Docker or Podman isn't running." A script that matched the old sentences needs the new ones.

### New config keys

None.

### Upgrade instructions

**The one-line installer on a Mac.** Run it again; it keeps your config.toml:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install.sh | bash
```

**The Mac installer.** [Download the disk image](https://github.com/aarora79/meru/releases/latest/download/Meru-macos-arm64.dmg),
open it, and run "Install Meru.app". It leaves your config and memories alone.

**Linux.** Run `install-linux.sh` again; it keeps your config.toml:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install-linux.sh | bash
```

**From source.**

```sh
cd meru
git pull origin main
git checkout v0.7.2
go install ./cmd/merud ./cmd/meru
launchctl kickstart -k gui/$(id -u)/com.meru.merud   # Linux: systemctl --user restart merud
```

Then, on a Mac that reads Apple Notes: macOS drops the Full Disk Access grant
when the `merud` binary changes. In System Settings, open Privacy & Security,
Full Disk Access, and turn `merud` off and on again.

**With Podman.** On a Mac, run `podman machine start` before you turn on Web
search. You need no `docker` alias: `merud` looks for the `podman` program
itself.

## Major features

### Web search runs with Podman

`merud` used to look only for a program named `docker`. A Mac with Podman got "Web search needs Docker", even with `docker` aliased to `podman` in the shell: `merud` runs programs without a shell, so it never sees an alias.

- `merud` looks for `docker` in its usual folders first, then `podman` in the same folders and in `/opt/podman/bin`. A computer with both keeps Docker.
- It checks the engine with the template Podman understands, since Podman's `info` names the version field differently.
- The Mac installer finds Podman too, and its Web search step names it.
- The [web search FAQ](https://github.com/aarora79/meru/blob/v0.7.2/docs/faq/web-search.md) covers `podman machine start`.

## Bug fixes

- **Ollama stopping mid-session showed a raw error.** Every question failed with a `dial tcp 127.0.0.1:11434: connect: connection refused` line. Now Meru says "Ollama isn't running, so Meru can't answer yet.", and Settings shows Ollama down. (#222)
- **Try again took the composer's attachments.** A file waiting for your next question joined the retried one and left the composer. Try again now resends only what the first asking carried. (#223)
- **The Usage screen opened on a table of numbers.** The charts now come first, with the table under them as Totals. (#224)
- **A new chat kept the last chat's scope.** After New chat, or `/new` in `meru chat`, a scope such as Mail stayed on, and answers looked only there with nothing on screen to say why. Each new chat now starts on Auto. (#225)
- **Rewording text you gave searched your files.** A question such as `rewrite "Meru streamlines my workflow…"` went to search and added about 7,000 tokens of excerpts. A question that opens with a writing verb such as rewrite, proofread or translate, and gives its text after a colon, quote or new line, now goes straight to the model. (#226)
