# Release v0.7.4 - Sign in to MCP servers on the internet, and answers that check every source

**November 2026**

Meru can now sign in to an MCP server on the internet that wants your OAuth sign-in, such as GitHub's or Slack's: you click Sign in, approve it in your browser, and Meru keeps the token on your machine. Questions about your own life now look in every connected source, mail search works the way Gmail expects, and pages Meru writes carry the photos you gave it.

---

## Upgrading from v0.7.3

### Breaking changes

There are no breaking changes in this release. Every config key from v0.7.3 still loads, and the transcripts and `meru.db` don't change. The socket protocol gains one op and one event; an older client skips the event, so it shows no Sign in button, but it keeps working.

### New config keys

These go on an `[[mcp.servers]]` entry, and only an entry that signs in needs them. An entry without them behaves as before.

| Key | Default | What it does |
|-----|---------|--------------|
| `[[mcp.servers]] auth` | `""` | `"oauth"` signs in to the server with OAuth. Needs a `url` and `remote = true`, and no `Authorization` header. |
| `[mcp.servers.oauth] client_id` | `""` | The app you registered with the server. Empty means Meru registers itself, which GitHub and Slack don't allow. |
| `[mcp.servers.oauth] client_secret` | `""` | The app's secret, as `secret:<name>`, with the value in `secrets.toml`. |
| `[mcp.servers.oauth] issuer` | `""` | The one authorization server this client may use, such as `https://github.com/login/oauth`. Must be https. |
| `[mcp.servers.oauth] scopes` | `[]` | What Meru asks for. Empty takes the server's list. |
| `[mcp.servers.oauth] redirect` | `""` | A fixed callback when the app requires one, such as Slack's `http://localhost:3118/callback`. Empty lets the system pick a port on `127.0.0.1`. |

### Upgrade instructions

**The one-line installer on a Mac.** Run it again; it keeps your config.toml:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install.sh | bash
```

**The Mac installer.** [Download the disk image](https://github.com/aarora79/meru/releases/latest/download/Meru-macos-arm64.dmg),
open it, and run "Install Meru.app". It leaves your config and memories alone.

**Linux.** Run `install-linux.sh` again; it keeps your config.toml:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install-linux.sh | bash
```

**From source.**

```sh
cd meru
git pull origin main
git checkout v0.7.4
go install ./cmd/merud ./cmd/meru
launchctl kickstart -k gui/$(id -u)/com.meru.merud   # Linux: systemctl --user restart merud
```

Then, on a Mac that reads Apple Notes: macOS drops the Full Disk Access grant
when the `merud` binary changes. In System Settings, open Privacy & Security,
Full Disk Access, and turn `merud` off and on again.

Update Meru.app along with `merud`: the Sign in button and `/signin` come with
the new app. To add GitHub or Slack, follow
[the sign-in FAQ](https://github.com/aarora79/meru/blob/v0.7.4/docs/faq/oauth-mcp-server.md).

## Major features

### Sign in to MCP servers on the internet

A server entry with `auth = "oauth"` signs in through your browser. (#245)

- **Where you sign in.**
  - The desktop app has a **Sign in** button on the server's Settings card, and another above an answer whose question needed that server. Its composer also takes `/signin <server>`.
  - `meru chat` takes `/signin [server]`, and shows a line that names it.
  - `meru mcp login <name>` signs in from a terminal.
  - A question asked with `meru` prints the login command.
- **Servers that register Meru, and ones that don't.** With no `[mcp.servers.oauth]` table, Meru registers itself with the server. GitHub and Slack need an app you register once; the FAQ has the steps for both.
- **What Meru keeps.** The token sits in `~/.meru/oauth/<server>.json`, readable only by you, and never goes into a log, a span or an error. Meru saves a refreshed token. If the service refuses one, the server asks you to sign in again. Removing a server's entry deletes its token.
- **What it trusts.** The browser's answer arrives on a loopback port that takes one request. The sign-in runs PKCE and checks `state`. Its requests use https only, follow no redirect and use no proxy.
- `mcp_status` shows the new state `sign_in`, and a tools turn sends the event `sign_in_needed`, which `meru run --json` passes to scripts.

[PR #245](https://github.com/aarora79/meru/pull/245)

### Answers that look in every source you connected

A question about your own life, such as what you agreed by email last week, now checks each place that could hold the answer: your files, Apple Notes, and each MCP server such as `google` or `obsidian`. (#242)

- **The system prompt lists your sources** when a turn's tools reach two or more of them. For "last", "latest" or "recent", it says to search by date, newest first.
- **A new built-in skill, `mail-research`,** searches Gmail with its own query words, such as `after:`, `from:` and `has:attachment`, opens attachments, and quotes amounts exactly. An existing install gets it on its next start.
- **`analyze_table` reads a document.** Given a PDF, Word or text file, it returns the text instead of refusing.
- **An amount nothing backs gets a note.** A money amount in the answer that appears in nothing the turn read is flagged, so check it before you rely on it.

[PR #242](https://github.com/aarora79/meru/pull/242)

### Photos in the pages Meru writes

Ask for a card or a poster from a photo, and the page Meru saves now carries the photo. (#244)

- `write_file` and `edit_file` put each picture an HTML page names from the output folder into the page itself, so the page shows it anywhere. Web addresses and paths outside the folder stay as they are. The limits are 16 MB a picture and 40 MB a page.
- An answer that claims it wrote or rebuilt a file, on a turn that wrote none, gets a note.
- A follow-up question keeps the path of a file the turn downloaded, so it finds the photo, not some other picture in your folders.

[PR #244](https://github.com/aarora79/meru/pull/244)
