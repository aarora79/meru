# Release v0.4.18 - Speak Your Question

**October 2026**

Meru.app has a microphone. Press it, speak, press it again, and your words
land in the question box, where you check them before you press Send. Whisper
turns the sound into text on your Mac, outside Ollama, so it never pushes
Meru's own models out of memory, and Meru keeps no recording.

---

## Upgrading from v0.4.17

### Breaking changes

There are no breaking changes in this release.

Three things to know:

- **Voice is off until you turn it on**, in Meru.app's Settings,
  Connections, Speech to text, or with `meru mcp set whisper enabled=true`.
  Turning it on downloads `whisper-server` (8 MB) and one speech model:
  148 MB for the `lite` profile, 574 MB for `full`.
- **Macs with Apple silicon only, for now.** On Linux and Windows the
  connector stays off and says why.
- **Apple Notes needs its grant again.** A new `merud` build loses its Full
  Disk Access. After the update, open System Settings, Privacy & Security,
  Full Disk Access, and turn `merud` off and on again.

Meru.app asks macOS for the microphone the first time you press it. A Mac
with no microphone, such as a Mac Studio or a Mac mini, needs one plugged in:
AirPods, a headset or a webcam.

### New config keys

| Key | Default | What it does |
|-----|---------|--------------|
| `[connectors.whisper] enabled` | `false` | turns speech to text on |
| `[connectors.whisper] model` | the profile's: `ggml-base.en.bin` for `lite`, `ggml-large-v3-turbo-q5_0.bin` for `full` | the speech model; the first hears English, the second many languages |

A `config.toml` without the table keeps voice off.

### Upgrade instructions

**The one-line installer.** Run it again; it keeps your `config.toml`:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install.sh | bash
```

**The Mac installer.** [Download the disk image](https://github.com/aarora79/meru/releases/latest/download/Meru-macos-arm64.dmg),
open it, and open "Install Meru.app". The first time, macOS refuses because
Apple hasn't checked Meru: click Done, then Open Anyway in System Settings,
Privacy & Security. The installer leaves your config and memories alone.

**From source.**

```sh
cd meru
git pull origin main
git checkout v0.4.18
go install ./cmd/merud ./cmd/meru
make desktop-app && ditto bin/Meru.app /Applications/Meru.app
launchctl kickstart -k gui/$(id -u)/com.meru.merud   # or: pkill merud; merud &
```

Then turn on speech to text in Settings, Connections, and give `merud` Full
Disk Access again if you use Apple Notes.

## Major features

### Voice in Meru.app

- **The microphone button** sits beside the attach button. While it records
  it turns red, and the line above the box counts the seconds. A second
  press, or 60 seconds, stops it.
- **You check the words.** They land in the box after anything you typed,
  with "Check the words, then press Send." Nothing goes without your press.
- **Fast.** On an M4 Max with the larger model, the first recording after a
  quiet spell took 3.6 seconds while the speech server started; the next
  ones took 0.3 to 0.4 seconds, a 26-second recording included.
- **Private.** The sound goes from Meru.app to `merud` to `whisper-server` on
  127.0.0.1, behind a random path made for each start, so no web page in
  your browser can reach it. Nothing writes the sound to disk, and the log
  holds the length and the time, never the words. The answer model never
  hears the sound: it gets the text you send.

### Speech to text with Whisper, run by Meru

Meru runs whisper.cpp's `whisper-server` as a connector, like Obsidian and
Google: it downloads the program and the model when you turn it on, starts
the server when you record, and stops it after ten idle minutes.

- **Why Whisper, not a model in Ollama.** We tried Gemma 4, whose small
  models take audio in Ollama. At 7.4 GB it pushed one of Meru's models out
  of memory, so a spoken question waited about 5 seconds for its first word,
  and as a chat model it sometimes answered the spoken question instead of
  writing it down. Whisper only writes down speech, and takes 445 MB with
  `base.en` or 890 MB with `large-v3-turbo`, in its own process.
- **Built by Meru's CI.** whisper.cpp publishes no macOS `whisper-server`, so
  a GitHub Actions workflow builds it for Apple silicon from v1.9.5's pinned
  source, checks it, and publishes it as the release
  [whisper-server-v1.9.5](https://github.com/aarora79/meru/releases/tag/whisper-server-v1.9.5),
  with a signed record of how it was built (`gh attestation verify
  whisper-server-darwin-arm64 --repo aarora79/meru`).
- **Pinned.** The program and both models are pinned by SHA-256; the models
  come from Hugging Face at a fixed commit.

## What's new

### For scripts and the terminal
- `meru transcribe recording.wav` turns a WAV recording into text through
  `merud`, and prints "(Meru heard no words.)" for silence (#147).

### Under the hood
- Connectors have a new kind, `service`: a downloaded program `merud` starts
  on loopback and talks plain HTTP to, run by its own supervisor (#145).
- A binary connector may pin extra downloads, `[[install.files]]`, and
  downloads only the one a choice picks (#145).
- A request on the socket may now run to 4 MiB, room for a minute of audio;
  events stay at 1 MiB (#147).
- A new metric, `meru.speech.duration`, with the model and the outcome
  (#147).

### Documentation
- ARCHITECTURE.md has a Speech to text section, mirrored in the level 100,
  200 and 300 pages, and the harness page says that a spoken question
  reaches a turn as text (#143 to #148).
- The README names voice among what Meru does (#148).
