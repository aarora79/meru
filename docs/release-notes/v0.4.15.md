# Release v0.4.15 - Picture Questions Load the Right Skill

**October 2026**

A question about the pictures in your folders, such as "find pictures that look
like a coffee shop receipt", now loads the `file-research` skill and stays in
your folders, where it used to load `web-research` and search the web first.
`meru check` can also send a picture with a question, so you can test picture
questions on your own setup.

---

## Upgrading from v0.4.14

### Breaking changes

There are no breaking changes. One step brings the new skill text to an
existing install:

**Reset `file-research`.** `merud` copies a built-in skill only when its folder
is missing, so an install from before this release keeps the old
`file-research`, which doesn't mention pictures. Bring the new one with:

```sh
meru skills reset file-research
```

If you edited your copy, `meru skills show file-research` prints it first, so
you can keep your changes.

### New config keys

None.

### Upgrade instructions

**The one-line installer.** Run it again; it keeps your `config.toml`:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install.sh | bash
```

**The Mac installer.** [Download the disk image](https://github.com/aarora79/meru/releases/latest/download/Meru-macos-arm64.dmg),
open it, and open "Install Meru.app". The first time, macOS refuses because
Apple hasn't checked Meru: click Done, then Open Anyway in System Settings,
Privacy & Security. The installer leaves your config and memories alone.

**From source.**

```sh
cd meru
git pull origin main
git checkout v0.4.15
go install ./cmd/merud ./cmd/meru
make desktop-app && ditto bin/Meru.app /Applications/Meru.app
launchctl kickstart -k gui/$(id -u)/com.meru.merud   # or: pkill merud; merud &
```

Then run `meru skills reset file-research`, as above.

## Major features

### `file-research` covers pictures

The fast model picks skills from their descriptions, and `file-research` named
only notes, documents, papers, code and PDFs. It now names pictures, photos,
screenshots and receipts, and brings `search_images` and `view_image` with its
four other tools.

- On the skill pick's four picture questions, asked three times each on
  MiniCPM5-2B, right picks rose from 3 of 12 to 9 of 12. Over all 25 labelled
  questions they rose from 53 of 75 to 60 of 75.
- A second change, telling `web-research` it isn't for pictures in your folders,
  dropped the overall score to 44 of 75, since it pulled questions about current
  facts away from that skill. It stayed out.

[PR #127](https://github.com/aarora79/meru/pull/127)

### `meru check` sends pictures

A line in your check file can name a picture to send with its question:

```json
{"id": "like-this", "category": "images", "session": "receipts", "image": "~/Pictures/receipt.jpg", "question": "Find receipts like this one in my folders", "want": {"sources_any": [".jpg", ".png"]}}
{"id": "itemize", "category": "images", "session": "receipts", "question": "Itemize each of those receipts and total them", "want": {"tools": ["view_image"]}}
```

`~/` stands for your home folder. A picture `merud` won't take, or one that
isn't there, fails that check alone, and the rest of the file still runs.
[docs/running.md](https://github.com/aarora79/meru/blob/v0.4.15/docs/running.md#check-answers-on-your-own-files)
has the format.

[PR #126](https://github.com/aarora79/meru/pull/126)
