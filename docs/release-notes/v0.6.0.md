# Release v0.6.0 - Meru on Linux

**October 2026**

Meru now installs and runs on Linux with one command, tested on Ubuntu 24.04
with an NVIDIA card. On Linux it picks the answer model by the card's memory,
runs `merud` as a systemd user service, and offers the desktop app and speech
to text. On every computer, Meru now knows its own name and model: asked
"who are you", it no longer makes up another.

---

## Upgrading from v0.5.0

### Breaking changes

There are no breaking changes in this release. Config keys, the socket
protocol, the transcripts and `meru.db` are as they were in v0.5.0.

### Upgrade instructions

**The one-line installer on a Mac.** Run it again; it keeps your config.toml:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install.sh | bash
```

**The Mac installer.** [Download the disk image](https://github.com/aarora79/meru/releases/latest/download/Meru-macos-arm64.dmg),
open it, and run "Install Meru.app". It leaves your config and memories alone.

**Linux.** The new installer is new in this release. Run it to install, and
again to update; it keeps your config.toml:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install-linux.sh | bash
```

**From source.**

```sh
cd meru
git pull origin main
git checkout v0.6.0
go install ./cmd/merud ./cmd/meru
launchctl kickstart -k gui/$(id -u)/com.meru.merud   # Linux: systemctl --user restart merud
```

If you use the Apple Notes tools, macOS drops the Full Disk Access grant when
the `merud` binary changes. In System Settings, open Privacy & Security, Full
Disk Access, and turn `merud` off and on again.

## Major features

### Install on Linux with one command

`install-linux.sh` ships with the release. It downloads Meru, checks every file
against `SHA256SUMS`, and puts `meru` and `merud` in `~/.local/bin`. It then
offers, one step at a time or all at once:

- the desktop app, with the GTK 4 and WebKitGTK 6.0 libraries it needs from
  apt, an entry in the app menu and the icon;
- Ollama, through Ollama's own script;
- `meru setup`, which picks the models, folders and web search;
- `merud` as a systemd user service, with lingering so it starts at boot.

On a machine with no systemd, such as a container or WSL, it starts Ollama
itself and tells you how to start `merud`. `MERU_YES=1` answers yes to every
step, for a script.

The Linux desktop app joins the release as
`meru-desktop-v0.6.0-linux-amd64.tar.gz` shortly after the rest: it builds on
Ubuntu, not on the Mac that builds the release.

[PR #180](https://github.com/aarora79/meru/pull/180) ·
[PR #185](https://github.com/aarora79/meru/pull/185)

### A model that fits the graphics card

`merud` and `meru setup` now read the computer the same way on every system,
through one table of what differs between macOS, Linux and Windows. On Linux
with an NVIDIA card, `meru setup` reads the card's memory and suggests the
answer model that fits: on a 45 GB L40S it suggests `qwen3.6:35b`. `merud`
sizes the context window from the card's memory, and tells the model which
card it runs on, so a question about the GPU gets an answer about this
machine. The desktop app says "this computer" on Linux where it said "this Mac".

Macs get the same model as before.

[PR #179](https://github.com/aarora79/meru/pull/179)

### Speech to text on Linux

The whisper connector now has a Linux build of `whisper-server` for x86-64,
built from pinned whisper.cpp source by Meru's own workflow. Turn on Speech to
text in Settings, Connections, and the microphone in the desktop app and
`meru transcribe` work as they do on a Mac. On a computer with no build, the
connector says so before it says it is off.

## Bug fixes

- Asked "who are you", the answer model once called no tool and said "My name
  is Jina. I use a Mistral model." Every prompt now names Meru and the answer
  model, so it answers from the fact. (#181)

## What's new

### Documentation

- The README, the 100-level architecture page, the landing page, the install,
  update and start/stop FAQ pages, the slides and the poster now cover Linux.
  (#182)
- The slide PDFs are printed again with the Linux text. (#186)
- The README and the landing page point to the Mac and the Linux installers up
  front, each command with its own Copy button. The `meru-install` skill reads
  the system, runs the right installer, and checks `merud`, `meru`, `meru chat`
  and the desktop app in turn. (#188)
- ROADMAP.md closes v0.6 with Meru on Linux. Digests, notifications,
  third-party MCP servers ([#87](https://github.com/aarora79/meru/issues/87))
  and the open issues move to a new v0.7 milestone.
- ARCHITECTURE.md gains "One table of differences", and `docs/running.md` a
  table of answer models by GPU memory. (#179)
