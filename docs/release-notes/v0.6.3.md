# Release v0.6.3 - Word, Excel and CSV files, and exact answers about tables

**November 2026**

Meru now reads Word, Excel and CSV files, and a new tool, `analyze_table`,
answers questions about a sheet exactly: totals, counts, averages, medians and
percentiles, worked out by Meru's own code, never by the model. A follow-up
question now knows which tools the last two turns ran, a question that runs out
of tool rounds says so and offers Continue, and a built-in tool added in a new
release shows as New instead of staying off with no word.

---

## Upgrading from v0.6.2

### Breaking changes

This release has no breaking changes. An existing `config.toml` loads as it is,
and `meru.db`, the transcripts and the socket protocol stay compatible: the
protocol gains optional fields only, and a client from v0.6.2 keeps working.

### New config keys

| Key | Default | What it does |
|-----|---------|--------------|
| `[builtin] off` | `[]` | The built-in tools you chose to keep off. It turns nothing off by itself: a tool is on only while `[builtin] tools` lists it. Settings and `/mcp` write it when you turn a built-in off. |

A `config.toml` without the key gets the default. `[builtin] tools` gains
`analyze_table` in the default list.

### Upgrade instructions

**The one-line installer on a Mac.** Run it again; it keeps your config.toml:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install.sh | bash
```

**The Mac installer.** [Download the disk image](https://github.com/aarora79/meru/releases/latest/download/Meru-macos-arm64.dmg),
open it, and run "Install Meru.app". It leaves your config and memories alone.

**Linux.** Run `install-linux.sh` again; it keeps your config.toml:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install-linux.sh | bash
```

**From source.**

```sh
cd meru
git pull origin main
git checkout v0.6.3
go install ./cmd/merud ./cmd/meru
launchctl kickstart -k gui/$(id -u)/com.meru.merud   # Linux: systemctl --user restart merud
```

Then:

- **Turn on `analyze_table` if your config lists its tools by hand.** Open
  Settings, Connections: the Meru card marks it **New**, off until you turn it
  on. In `meru chat`, `/mcp` shows it as "· new". If your list also lacks
  `search_files`, turn that on too: without it, Meru can't search your files by
  meaning, and a question about a data file can miss it.
- **Expect one longer scan.** The first scan after the upgrade indexes your
  `.docx`, `.xlsx`, `.csv`, `.tsv` and `.tab` files for the first time.
- **Apple Notes.** macOS drops the Full Disk Access grant when the `merud`
  binary changes. In System Settings, open Privacy & Security, Full Disk
  Access, and turn `merud` off and on again.

## Major features

### Word, Excel and CSV files

Search, `read_file` and `grep` now read `.docx`, `.xlsx`, and delimited text
files: `.csv`, `.tsv` and `.tab`.

- A Word file is read as text, by heading, so an answer cites the heading a fact
  sits under.
- A sheet is read row by row, each row labelled with its column names, and an
  answer cites the sheet and the rows, such as "budget.xlsx, Invoices, rows
  12–41". The first line of each piece names the file's path, so a question
  that names the folder finds a file whose cells don't.
- Dates read as dates, a formula as the value Excel saved with it, and Meru
  never runs a formula. A delimited file's separator (comma, semicolon, tab or
  pipe) is worked out from its first lines.
- `grep` reports a match as "sheet Invoices, row 14", and lists files whose names
  match.
- The old `.doc` and `.xls` formats stay out; Meru says to save them as `.docx`
  or `.xlsx`. A password-protected file says so.
- Every reader caps what a file may unpack into, so a hostile file can't fill
  memory or crash `merud`. Meru uses Go's standard library for all of it and
  adds no dependency.

[PR #198](https://github.com/aarora79/meru/pull/198), [PR #209](https://github.com/aarora79/meru/pull/209)

### `analyze_table`: exact answers about a sheet

Ask "How much did we spend on food tours in Amsterdam?" and the model calls
`analyze_table` with fixed fields. Meru's code reads every row and does the
sums. The model writes no code, and nothing reaches an interpreter.

- Filter rows (`=`, `<`, `contains`, `in` and more), group them by up to three
  columns, and work out `count`, `sum`, `avg`, `min`, `max`, `median` or any
  `percentile`; an interquartile range is p75 minus p25.
- Sums add whole cents, never floating-point numbers, so a column of amounts adds
  up to the cent.
- Called with only a file, the tool describes the sheet first: its columns,
  their types, sample values and the first rows.
- It only reads, so it runs without asking, and every call goes through
  `dispatch` like any tool.

[PR #199](https://github.com/aarora79/meru/pull/199), [PR #204](https://github.com/aarora79/meru/pull/204)

### Follow-up questions know which tools ran

A follow-up such as "how did you get that?" used to see only the earlier
questions and answers, and a model made up rows and tool steps to explain an
answer. Now the history of the last two turns carries one line per tool call:
the tool, its arguments, how it ended and the start of its result. Old chats gain
these notes too, and an incognito chat keeps them in memory only.

[PR #205](https://github.com/aarora79/meru/pull/205)

### A question that runs out of tool rounds says so

A question that used every tool round (`[agent] max_rounds`, 8 by default) used
to end "Sorry, I couldn't answer that." It now says Meru used all its rounds,
names the tools it tried, and offers Continue in Meru.app and `meru chat`. An
answer whose last words only announce a next step, such as "Let me find the
date.", keeps them, with a note under it, instead of passing as an answer. Before
the last round, a reply that only plans a step gets one nudge to take it.

[PR #206](https://github.com/aarora79/meru/pull/206)

### New built-in tools show as New

A config that lists its tools by hand used to leave a tool from a newer release
off, with nothing to say it existed. Meru still never turns a new tool on by
itself: your list stays the allowlist. Such a tool now shows as **New** in
Settings and `/mcp` until you turn it on or off, and `merud` names it at
startup.

[PR #207](https://github.com/aarora79/meru/pull/207)

## What's new

### Answers
- An answer that links a `file://` path that doesn't exist gets a notice under
  it. (#195)
- `grep` runs a pattern such as `a|b` as a regular expression when the plain-text
  search finds nothing, and says so. (#209)

### Documentation
- A design document for the Word, Excel and CSV feature, with two figures, in
  [docs/design/](https://github.com/aarora79/meru/blob/v0.6.3/docs/design/word-excel-csv.md). (#198)
- A FAQ page: [How do I ask about a spreadsheet?](https://github.com/aarora79/meru/blob/v0.6.3/docs/faq/spreadsheets.md) (#199)
- The four slide decks are brought up to v0.6.2. (#194)
- Every piece of prose in the repository follows version 1.2 of the writing
  skill, with a scanner for the common tells. (#197)
