# Release v0.4.20 - Still Working

**October 2026**

Meru.app and `meru chat` now show that Meru is still working when a model
goes quiet after its first words, as it does while it writes a long file.
Two new slide decks explain Meru, one for individuals and one for
organizations, and every deck gets back and forward buttons.

---

## Upgrading from v0.4.19

### Breaking changes

There are no breaking changes in this release.

Two things to know:

- **Update Meru.app with `merud`.** The new working line is in both
  clients.
- **Apple Notes needs its grant again.** A new `merud` build loses its Full
  Disk Access. After the update, open System Settings, Privacy & Security,
  Full Disk Access, and turn `merud` off and on again.

### New config keys

None.

### Upgrade instructions

**The one-line installer.** Run it again; it keeps your `config.toml`:

```sh
curl -fsSL https://github.com/aarora79/meru/releases/latest/download/install.sh | bash
```

**The Mac installer.** [Download the disk image](https://github.com/aarora79/meru/releases/latest/download/Meru-macos-arm64.dmg),
open it, and open "Install Meru.app". The first time, macOS refuses because
Apple hasn't checked Meru: click Done, then Open Anyway in System Settings,
Privacy & Security. The installer leaves your config and memories alone.

**From source.**

```sh
cd meru
git pull origin main
git checkout v0.4.20
go install ./cmd/merud ./cmd/meru
make desktop-app && ditto bin/Meru.app /Applications/Meru.app
launchctl kickstart -k gui/$(id -u)/com.meru.merud   # or: pkill merud; merud &
```

## Major features

### Meru says when it's still working

After its first words, a model can go quiet for a minute or more while it
writes a long tool call, such as a whole page for `write_file`. Ollama sends
a tool call only when it's done, so nothing reached the screen. In one turn
the model wrote a 22,000-character page for 90 seconds, and Meru.app showed
only a blinking cursor; the user asked whether it was still working.

- **Meru.app** keeps its Working label for as long as a turn runs. After
  five quiet seconds it reads "Still working · 52 s", and its tooltip says
  the model may be writing something long, such as a file.
- **`meru chat`** shows the same line under the answer, with its spinner.
- A wait for your approval doesn't count as quiet.

[PR #163](https://github.com/aarora79/meru/pull/163)

### Slides for individuals and for organizations

- **Meru for individuals**, 13 slides: Meru.app, what it does with your
  files, mail, notes and pictures, what it remembers, what leaves your Mac,
  how you stay in charge, which Mac you need, getting started, and what it
  does not do yet.
- **Meru for organizations**, 14 slides, for a CTO or CIO weighing a pilot
  and a platform team weighing a managed offering: what leaves the machine,
  the controls a security team can check, the audit trail, measured quality,
  speed and memory, what rollout takes, what Meru lacks for a fleet, and a
  four-week pilot. It sticks to facts and names its gaps.

Both come as HTML and PDF in `docs/slides/`, and the landing page's top bar
links to them as "Meru for individuals" and "Meru for organizations".
