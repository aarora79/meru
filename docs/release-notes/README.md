# Release notes

One file per release, newest first. The `release-notes` skill in
`.claude/skills/` writes each one, and `make release` uses it as the GitHub
release's text ([releasing.md](../releasing.md)).

- [v0.4.20](v0.4.20.md): Meru says when it's still working, and slides for individuals and for organizations
- [v0.4.19](v0.4.19.md): room to read: a context window sized for the answer model, Continue, and websites you trust
- [v0.4.18](v0.4.18.md): voice in Meru.app, with Whisper run on your Mac, and `meru transcribe`
- [v0.4.17](v0.4.17.md): Meru reads your Apple Notes, live and read-only, and the installer helps with the grant
- [v0.4.16](v0.4.16.md): a scope you pick fences the tools that run, and the architecture documents match the code
- [v0.4.15](v0.4.15.md): picture questions load the right skill, and `meru check` sends pictures
- [v0.4.14](v0.4.14.md): the answer model reads the pictures a search finds, and a text-only model names one that can
- [v0.4.13](v0.4.13.md): image search, by words or like a picture you attach, and one search model for text and images
- [v0.4.12](v0.4.12.md): usage charts in the app, a /metrics page for Prometheus, and no Grafana stack
- [v0.4.11](v0.4.11.md): pages that need JavaScript, Google as a connector, and connectors you set up and fix from Settings, `meru chat` and the installer
- [v0.4.10](v0.4.10.md): connectors: Meru installs, runs and restarts Obsidian and web search for you, and waits for Ollama
- [v0.4.9](v0.4.9.md): past chats you can find, file, tag and delete, and honest answers about time and tools
- [v0.4.8](v0.4.8.md): the Mac installer opens after a download, and the benchmark in the README
- [v0.4.7](v0.4.7.md): benchmark charts of accuracy against time, and each Mac's default model
