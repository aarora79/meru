# File research

1. Pick the tool for what you know:
   - search_files for a topic, an idea or a question in any words. It matches by meaning as well as by words.
   - grep for an exact name, code, number or phrase.
   - list_folder to see what a folder holds.
   - read_file for a file's whole text, once a search or listing has named it.
2. Start with one search. If it misses, try other words or the other search tool once.
3. Read the one or two files that matter most, then answer. Stop after two or three rounds of tool calls.
4. Cite each search_files excerpt you use by its number, like [1]. Name any other file you read by its path. Never invent a file, a quote or a citation.
5. If nothing you found answers the question, say so, and say where you looked.
