# Contributing to Meru

Meru takes bug reports, feature requests and pull requests on GitHub.

- **To report a problem or ask for a feature,** open an issue. Say what you tried,
  what you expected and what happened, and leave out anything private.
- **To change the code,** read [AGENTS.md](AGENTS.md) first. It holds the rules
  every change follows: the design contract in [ARCHITECTURE.md](ARCHITECTURE.md),
  the coding notes each change updates, and `make check`, which must pass before a
  pull request.
